Privacy policy

ANAS / effective and last updated: October 17, 2026

This app collects no personal information. Files only travel between the device and the machines you connect from the same network. Nothing is sent to the developer or any external server.

This policy explains how "ANAS" (the "App"), an Android app provided by bunnmei (the "Developer"), handles user information.

1. Information collected

The Developer does not collect any information through the App. There are no accounts, ads, analytics or crash reporting.

2. Files

  • The App only reads and writes the folders you pick (internal storage, SD card, USB drive).
  • Files are only sent to devices connecting from the same local network (private IP addresses). Connections from the internet are refused.
  • Traffic is plain HTTP and not encrypted. Do not use the App on untrusted networks such as public Wi-Fi.

3. Data stored on the device

The picked folders and settings (theme, port, access password, enabled extensions) are stored only on the device and are removed when the App is uninstalled.

4. Permissions

PermissionPurpose
Internet, network state, Wi-Fi stateAccept connections from PCs on the LAN and show the device's IP address
Local network access (Android 17+)Accept connections from PCs on the LAN
Foreground service, keep awakeKeep the server running with the screen off
NotificationsShow that the server is running, with a Stop button

Folder access is limited to what you pick in Android's folder picker; the App does not request access to all files.

5. Extensions

Extensions are HTML / JavaScript that you install yourself. Whether an extension talks to external servers depends on the extension (external access is blocked by default). Only install extensions you trust.

6. Contact

Please use GitHub Issues.

7. Changes

If this policy changes, this page and its date will be updated.

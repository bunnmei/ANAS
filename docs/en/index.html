Turn a spare Android
into your own NAS.

Read and write the internal storage, SD card and USB drives from any browser on the same Wi-Fi / LAN.
Nothing to install on your PC.

Read the guide GitHub

Features

Just a browser

Upload (whole folders, drag & drop), download (whole folders as zip too), rename and delete. Videos can be seeked while streaming.

SD cards and USB drives

SSDs and USB sticks behind a USB hub work as-is. Files over 4 GB are fine on exFAT.

Per-folder web apps (extensions)

Put HTML / CSS / JS in a folder like /.jisui/ and it becomes a web app dedicated to that folder.

LAN only

Only private IP addresses on your network can connect. An optional password is available.

Requirements

  • An Android device running Android 9 or later
  • A PC on the same Wi-Fi / LAN (any OS with a browser)
  • Optionally an SD card or USB drive (USB OTG / USB hub)

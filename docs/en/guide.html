ANAS / Android 9 or later

Three steps. Tap "Add storage" → "Start" → open the URL shown (http://192.168.x.x:8080) in a browser on your PC.

1. Add storage

  1. Tap "Add storage" on the Home tabAndroid's folder picker opens.
  2. Pick the folder to shareUse the ☰ menu to switch between internal storage, SD card and USB drives. For SD cards and USB drives you can pick the top level.
  3. Tap "Use this folder" → "Allow"The folder stays available after restarting the app.
The top of internal storage can't be picked

Since Android 11 the top of internal storage and the Download folder can't be picked. Create a folder such as "NAS" in the picker and choose it.

You can register several storages; in the web UI they appear as disk1, disk2, … If you unplug a USB drive it is shown as "not connected" and works again once plugged back in.

2. Start the server

  1. Tap "Start"On Android 13+ you are asked for the notification permission. The notification has a "Stop" button.
  2. Check the URLA URL like http://192.168.1.10:8080 is shown, with copy and "open in browser" buttons.

The server keeps running with the screen off or the app closed (foreground service). Stop it from the app or the notification.

3. Use it from a PC browser

Connect the PC to the same Wi-Fi / LAN and open the URL.

Finding files

Type a plain sentence in the search box at the top. ANAS searches file and folder names, types, dates and sizes (not file contents). Japanese and simple English work: "PDF uploaded within 3 days", "photos last week", "1GB video largest". The way ANAS read your query is shown above the results, and if nothing matches exactly it shows similar names.

Searching uses an index kept on the device. It is built shortly after the server starts and rebuilt every 12 hours (or right away with "rebuild index" on the search page). Uploads, renames and deletes made through ANAS are reflected immediately. The first build can take a while with many files (tens of minutes for hundreds of thousands).

Play music and video

Audio (MP3, M4A, FLAC, …) and video (MP4, WebM, …) play right in the page when you click (tap) the name.

  • Audio stays at the bottom of the screen and keeps playing while you browse other folders. When a track ends, the next one in the same folder starts ("Play all" above the folder starts from the top).
  • Video opens full screen. Close it with the close button or Back.
  • MKV, AVI and video compressed with H.265 and similar may not play in the browser. Use "Playlist" for those.

"Playlist" above the folder is an M3U file of the folder's audio and video. Open it in VLC or another player to stream without downloading (seeking works). In the phone app it is handed to your installed player app. If you set an access password, the player asks for it (any user name).

Mount it as a drive (WebDAV)

Turn on "Use WebDAV" under Settings → Network drive (WebDAV) in the app, and you can mount the NAS as a drive on your PC. File managers, editors and tools such as Claude Code can then open and save files normally. The address is http://<device IP>:<port>/dav/ (shown in Settings). Any user name works; the password is the access password.

PCHow
macOSFinder → Go → Connect to Server → http://192.168.1.108:8080/dav/
LinuxGNOME Files → Other Locations → dav://192.168.1.108:8080/dav/. To mount as a folder without root, use rclone: rclone config create anas webdav url=http://192.168.1.108:8080/dav/ vendor=other user=me pass=$(rclone obscure PASSWORD) then rclone mount anas:disk1 ~/anas --vfs-cache-mode writes
WindowsFile Explorer → Map network drive → http://192.168.1.108:8080/dav/disk1. If you set a password, Windows refuses Basic authentication over http by default: set BasicAuthLevel to 2 under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters and restart the WebClient service (or use a WebDAV app such as RaiDrive)
  • The connection is plain http. Use it only inside your LAN (ANAS refuses connections from outside). Setting a password is recommended.
  • "WebDAV read-only" makes the drive read-only from the PC (useful when letting AI tools look around).
  • Everything goes through Android's SAF, so listing huge folders or grepping everything is slower than a local disk. Moving to another folder copies then deletes, which takes time.

4. Browse from your phone (client)

Install ANAS on your everyday phone too, scan a QR code once, and open the NAS inside the app. The phone only views; it does not need to be a server.

  1. Open ANAS on the phone and choose "Just view another NAS (client)"In this mode the server never runs, and the app shows only the NAS page without tabs.
  2. On the server device, tap the QR button next to the address on "Home"A QR code for http://192.168.x.x:8080/ appears.
  3. On the phone, tap "Scan QR" and scan itThe app checks that it really is an ANAS server, saves it and opens it. From then on, opening the app shows the same NAS.
About QR scanning

QR codes are read by the Google Play services scanner, so ANAS needs no camera permission. The scanner is downloaded on first use (if you see "preparing", wait a moment and tap again). You can also type an address such as 192.168.1.10:8080.

The in-app browser only opens pages on the same LAN (private IP addresses). Links to external sites open in your normal browser, and images or scripts loaded from the internet are blocked, so extensions that rely on an external CDN (externalOrigins) may not fully work in the app. The server device has the same view in the "Browse" tab ("Open this device's server" opens its own NAS).

6. Troubleshooting

The phone app says it can't connect

Check that the ANAS server is running on the server device and that the phone is on the same Wi-Fi, then tap "Reload". The router assigns the server's IP address, so it can change; if it does, use "Scan QR again" in the menu (reserving the server's IP address in your router avoids this).

The PC can't open the URL

Make sure both are on the same network. Guest Wi-Fi and routers with "AP isolation" block device-to-device traffic. Mobile data (4G / 5G) does not work.

"Port 8080 is in use"

Another app uses the port. Change it in Settings and start again.

A USB drive shows "not connected"

It was unplugged or went to sleep. Plug it back in and reopen Home. If permission was lost, remove it and add it again.

Files over 4 GB fail to upload

FAT32 cards and drives are limited to 4 GB per file. Format them as exFAT.

Some file names are rejected

So that files also fit on SD cards and USB drives, names containing \ : * ? " < > | or ending in a space or period are not allowed.

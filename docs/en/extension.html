Extensions (special folders)

ANAS / spec version 1

Give a folder its own UI. Create a folder such as .jisui/ at the top of a storage, add anas.json and some HTML / CSS / JS, and a web app for that folder runs at http://device:8080/x/jisui/.

Full specification

All rules, the HTTP API, error codes and the CSP are in spec/EXTENSION_SPEC.md (Japanese). A running device also serves it at /_anas/spec.md, with SDK types at /_anas/sdk.d.ts.

1. Folder layout

/.jisui/              ← "." + id, at the top of a storage
  anas.json           ← manifest (required)
  app/                ← UI (index.html is the entry), served at /x/jisui/
  data/               ← data; the SDK can only read and write here

2. anas.json

{ "anas": 1, "id": "jisui", "name": "Scanned books", "version": "1.0.0", "icon": "icon.svg" }

id uses lowercase letters, digits, _ and -, and the folder name must be . + id. scope: "all" asks for access to the whole NAS, which the user must allow in the app. externalOrigins lists CDNs you load from; by default nothing external is allowed. network lists sites that ANAS (the device) fetches on the extension's behalf, e.g. ["https://www.amazon.co.jp", "https://*.media-amazon.com"]; the user must allow it in the app. home: true (with scope: "all") lets the extension replace the NAS start page.

3. SDK

<script type="module">
  import { anas, joinPath } from "/_anas/sdk.js";
  const entries = await anas.list("/");
  img.src = anas.fileUrl("/covers/a.jpg");
  await anas.upload(joinPath("/books", file.name), file, { onProgress: (d, t) => console.log(d / t) });
</script>

Also: zipUrl (download a folder as zip), streamUrl (for audio / video: seekable, also works in VLC etc.), playlistUrl (M3U8 playlist of a folder), stat, exists, readText, readJson, writeJson, listRecursive, mkdir, rename, remove. Include /_anas/base.css for the ANAS look with automatic light / dark.

Inside the ANAS app, the app theme is set as <html data-anas-theme="dark"> (or "light"), because on Android 9 prefers-color-scheme does not follow the app setting. If you write your own dark colors instead of using base.css, also match :root[data-anas-theme="dark"].

anas.search("PDF uploaded within 3 days") searches the files in your own data/ with a plain sentence (by name, type, date and size).

Fetching data from other sites

Browser JavaScript can't read sites that don't allow CORS. List them in network in anas.json, allow it in the app's Extensions tab, and the device fetches them for you.

const res = await anas.fetch("https://www.amazon.co.jp/dp/4000000000");
const doc = new DOMParser().parseFromString(await res.text(), "text/html");
const title = doc.querySelector("#productTitle")?.textContent?.trim();

// Save images straight into data/ without going through the browser
await anas.fetchToFile(imageUrl, "/.covers/4000000000.jpg", { overwrite: true });

Only allowed sites work, and redirect targets must be listed in network too. Devices on the LAN and the phone itself are never reachable this way. It also works inside the app's WebView.

Replacing the NAS start page

Put "scope": "all" and "home": true in anas.json, then turn on "Allow access to the whole NAS" and "Use as home screen" in the app's Extensions tab. Opening the NAS URL now shows your extension. Use the SDK's nas to work with files across the NAS.

import { nas } from "/_anas/sdk.js";
const [disk] = await nas.volumes();
const entries = await nas.volume(disk.id).list("/");   // paths from the storage root

The standard page is always available by adding ?ui=default to the URL (e.g. http://192.168.1.10:8080/?ui=default). Disabling or removing the extension switches back to the standard page automatically.

4. Installing

  1. From a zipWeb UI → "Extensions" → "Install from zip". Existing files in data/ are kept.
  2. Upload the folderAt the top of a storage use "Whole folder" to upload .jisui, then "Rescan".
  3. Create a template in the app"Extensions" tab → "Create".

5. Samples

Book shelf (.jisui)

Shelve scanned PDFs and image folders, with generated covers, two-page / right-to-left reading, reading position and drag & drop from a PC.

An example that replaces the NAS start page: storage and file lists, uploads and links to your extensions.

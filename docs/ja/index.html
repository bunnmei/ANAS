English

使っていない Android を、
自分だけの NAS に。

本体ストレージ・SD カード・USB ドライブを、同じ Wi-Fi / LAN の PC からブラウザで読み書きできます。
PC に追加のソフトは要りません。

使い方を見る GitHub

特徴

ブラウザだけで使える

アップロード（フォルダごと・ドラッグ＆ドロップ）、ダウンロード（フォルダごと ZIP でも）、名前の変更、削除。動画の途中から再生にも対応。

SD カードと USB ドライブ

USB ハブ経由の SSD や USB メモリもそのまま使えます。4GB を超えるファイルも扱えます（exFAT など）。

フォルダ専用の画面（拡張機能）

/.jisui/ のようなフォルダに HTML / CSS / JS を置くと、そのフォルダ専用の Web アプリになります。

スマホからも QR ひとつで

普段使いのスマホに ANAS を入れて「クライアント」にすると、サーバーの QR を読むだけでアプリの中から NAS を開けます。

LAN の中だけ

同じネットワークのプライベート IP からだけ接続できます。任意でパスワードも設定できます。

必要なもの

  • Android 9 以降の端末
  • 端末と同じ Wi-Fi / LANにつながった PC（ブラウザがあれば OS は問いません）
  • 必要に応じて SD カードや USB ドライブ（USB OTG / USB ハブ）

プライバシーポリシー

ANAS ／ 制定日・最終更新日：2026 年 10 月 17 日

このアプリは、個人情報を一切集めません。ファイルは端末と、利用者が同じネットワークから接続した機器のあいだでだけやり取りされ、開発者や外部のサーバーには送られません。

このプライバシーポリシーは、bunnmei（以下「開発者」）が提供する Android アプリ「ANAS」（以下「本アプリ」）で、利用者の情報をどう扱うかを説明するものです。

1. 集める情報

開発者は、本アプリを通じて利用者の情報を集めていません。アカウント登録、広告、解析ツール、クラッシュレポートの送信はありません。

2. ファイルの扱い

  • 本アプリは、利用者が選んだフォルダ（本体・SD カード・USB ドライブ）だけを読み書きします。
  • ファイルは、端末と同じローカルネットワーク（プライベート IP アドレス）から接続した機器にだけ送られます。インターネット上の機器からの接続は拒否します。
  • 通信は暗号化されていない HTTP です。信頼できないネットワーク（公衆 Wi-Fi など）では使わないでください。

3. 端末に保存する情報

選んだフォルダの場所、テーマ・ポート番号・アクセスパスワード・拡張機能の有効 / 無効といった設定は、端末の中にだけ保存します。アプリを削除すると消えます。

4. 使う権限

権限用途
インターネット・ネットワーク状態・Wi-Fi 状態LAN 内の PC からの接続を受け付け、端末の IP アドレスを表示するため
ローカルネットワークへのアクセス（Android 17 以降）LAN 内の PC からの接続を受け付けるため
前景サービス・スリープの防止画面を消してもサーバーを動かし続けるため
通知サーバーが動いていることと「停止」ボタンを表示するため

フォルダへのアクセスは、Android のフォルダ選択画面で利用者が選んだものだけに限られます（ストレージ全体へのアクセス権限は使いません）。

5. 拡張機能

拡張機能は利用者が自分で置く HTML / JavaScript です。拡張機能が外部と通信するかどうかは、その拡張機能の作り方によります（既定では外部への通信を禁止しています）。信頼できる拡張機能だけを入れてください。

6. お問い合わせ

GitHub の Issues からご連絡ください。

7. 変更

このポリシーを変更するときは、このページを更新し、最終更新日を改めます。

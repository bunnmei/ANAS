使い方

ANAS ／ Android 9 以降

3 ステップで使えます。アプリで「ストレージを追加」→「開始」→ PC のブラウザで表示された URL（http://192.168.x.x:8080）を開く。

1. ストレージを追加する

  1. 「ホーム」タブの「ストレージを追加」を押すAndroid のフォルダ選択画面が開きます。
  2. 公開するフォルダを選ぶ左上のメニュー（☰）から本体・SD カード・USB ドライブを切り替えられます。SD カードと USB ドライブは一番上をそのまま選べます。
  3. 「このフォルダを使用」→「許可」アプリを再起動しても、選んだフォルダはそのまま使えます。
本体ストレージの一番上は選べません

Android 11 以降の制限で、本体ストレージの一番上と Download フォルダは選べません。フォルダ選択画面で「NAS」などのフォルダを新しく作って選んでください。

複数のストレージを登録できます。Web 画面では disk1、disk2 … のように切り替えて使います。USB ドライブを抜くと「接続されていません」と表示され、挿し直すとまた使えます。

2. サーバーを開始する

  1. 「開始」を押す初回は通知の許可を求められます（Android 13 以降）。通知には「停止」ボタンが出ます。
  2. 表示された URL を確認するhttp://192.168.1.10:8080 のような URL が表示されます。コピーボタンや「ブラウザで開く」も使えます。

サーバーは画面を消しても、アプリを閉じても動き続けます（前景サービス）。止めるときはアプリか通知の「停止」を押します。

3. PC のブラウザで使う

PC を端末と同じ Wi-Fi / LANにつなぎ、表示された URL をブラウザで開きます。

やりたいこと操作
アップロード「アップロード」「フォルダごと」ボタン、またはファイル・フォルダを画面にドラッグ＆ドロップ
開く・ダウンロード名前をクリックするとブラウザで開きます（PDF・画像・動画など）。↓ ボタンでダウンロード
フォルダごとダウンロードフォルダの行の ZIP ボタン、または開いているフォルダの「ZIP でダウンロード」。端末の中で zip を作りながら送るので、大きなフォルダでも端末の空き容量は要りません（その分、ダウンロードの残り時間は表示されません）
名前の変更・削除各行の ✎ と 🗑 ボタン
隠しファイル「隠しファイルを表示」にチェック（. で始まるファイル）
ファイルを探す上部の検索欄に、ふつうの文章で入れます（下の「ファイルを探す」）
拡張機能上部の「拡張機能」、またはフォルダを開いたときの「専用画面で開く」

ファイルを探す

上部の検索欄に、ふつうの文章で入れます。ファイル名・フォルダ名・種類・日時・サイズから探します（ファイルの中身は見ません）。

  • 「3日以内にアップロードしたファイル」「昨日から追加したPDF」: ANAS で追加した日時で探します
  • 「先週編集したエクセル」「去年の確定申告」「10月15日の写真」: 更新日時で探します
  • 「仕事の議事録のメモ」「mdかtxt」「1GB以上の動画 大きい順」: 言葉・種類・サイズで探します

どう読み取ったかは検索結果の上に表示されます。名前が少し違っても（「議事禄」など）、似た名前のものを探します。

検索には、端末の中に作る索引を使います。サーバーを開始して少しすると作り始め、そのあとは 12 時間ごとに作り直します（検索画面の「索引を作り直す」でもすぐに作り直せます）。ANAS でアップロード・名前の変更・削除をしたものは、その場で反映されます。ファイルが多いと最初の索引作りに時間がかかります（数十万件で数十分ほど）。PC から SD カードに直接コピーしたものは、次の作り直しのときに「追加した」ものとして見つかります。

PC にドライブとしてつなぐ（WebDAV）

アプリの「設定 → ネットワークドライブ（WebDAV）」で「WebDAV を使う」をオンにすると、NAS を PC のドライブとしてつなげます。エクスプローラー・Finder・ファイルマネージャー、エディタや Claude Code などから、ふつうのファイルとして開いて保存できます。接続先は http://<端末の IP>:<ポート>/dav/ です（設定画面に表示されます）。ユーザー名は何でもよく、パスワードはアクセスパスワードです。

PCつなぎ方
macOSFinder の「移動 → サーバへ接続」に http://192.168.1.108:8080/dav/ を入れる
LinuxGNOME の「ファイル」なら「他の場所」に dav://192.168.1.108:8080/dav/。フォルダとしてマウントするなら、root 不要の rclone: rclone config create anas webdav url=http://192.168.1.108:8080/dav/ vendor=other user=me pass=$(rclone obscure パスワード) → rclone mount anas:disk1 ~/anas --vfs-cache-mode writes
Windowsエクスプローラーの「ネットワークドライブの割り当て」に http://192.168.1.108:8080/dav/disk1。パスワードを設定している場合、Windows は標準では http の Basic 認証を拒否するので、レジストリ HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters の BasicAuthLevel を 2 にして WebClient サービスを再起動する必要があります（RaiDrive などの WebDAV アプリを使う方法もあります）
  • 通信は暗号化されない http です。同じ LAN の中だけで使ってください（LAN の外からの接続は ANAS が拒否します）。パスワードの設定をおすすめします。
  • 「WebDAV は読み取り専用」をオンにすると、PC からは読むだけになります（AI ツールに触らせるときなど）。
  • 端末の中では SAF を通るので、ファイルの多いフォルダの一覧や全文検索（grep など）は PC のディスクより遅くなります。別のフォルダへの移動は、中身をコピーしてから消すので時間がかかります。

4. スマホで見る（クライアント）

普段使いのスマホにも ANAS を入れると、QR を読むだけでアプリの中から NAS を開けます。サーバーにする端末とは別に、見るだけの端末として使えます。

  1. スマホで ANAS を初めて開き、「ほかの NAS を見るだけ（クライアント）」を選ぶこの使い方ではサーバーは動かず、タブもなくなって NAS の画面だけになります。
  2. サーバーの端末で「ホーム」→ アドレスの横の QR ボタンを押すhttp://192.168.x.x:8080/ の QR が出ます。
  3. スマホで「QR を読む」を押して読み取る本当に ANAS のサーバーかを確かめてから保存し、そのまま開きます。次からはアプリを開くだけで同じ NAS が出ます。
QR の読み取りについて

QR は Google Play 開発者サービスのスキャナーで読み取るので、ANAS にカメラの権限は要りません。初めて使うときはスキャナーのダウンロードが必要です（「準備しています」と出たら少し待ってからもう一度押してください）。読めないときは「アドレスを入力」に 192.168.1.10:8080 のように入れても接続できます。

できること説明
アップロード「アップロード」でファイルを選べます（複数可）。「フォルダごと」は Android の制限で使えません
ダウンロードファイル・フォルダの ZIP は Download フォルダに保存され、通知に表示されます。拡張機能が作ったファイル（KiCad のシンボルなど）は保存先を選んで保存します
戻る端末の「戻る」でページを 1 つ戻ります
メニュー（⋮）QR を読み直す・普段のブラウザで開く・設定

アプリの中で開くのは同じ LAN（プライベート IP）のページだけです。外部サイトへのリンクは普段のブラウザで開き、ページが外部から画像やスクリプトを読み込もうとしても止めます。そのため、外部の CDN を使う拡張機能（externalOrigins）はアプリの中では一部が動きません。サーバーの端末でも「ブラウズ」タブから同じように使えます（「この端末のサーバーを開く」で自分の NAS も開けます）。

6. 困ったときは

スマホのアプリで「接続できません」と出る

サーバーの端末で ANAS のサーバーが動いているか、スマホが同じ Wi-Fi につながっているかを確認して「再読み込み」を押してください。サーバーの IP アドレスはルーターが割り当てるので、変わることがあります。そのときはメニューの「QR を読み直す」で登録し直してください（ルーターの設定でサーバーの端末の IP を固定しておくと便利です）。

PC から URL を開けない

PC と端末が同じネットワークにつながっているか確認してください。ゲスト Wi-Fi や「AP アイソレーション（プライバシーセパレーター）」が有効なルーターでは、端末どうしで通信できません。モバイルデータ（4G / 5G）では使えません。

「ポート 8080 は使用中です」と出る

ほかのアプリが同じポートを使っています。設定でポート番号を変えてから、もう一度「開始」を押してください。

USB ドライブが「接続されていません」になる

ドライブが取り外されたか、スリープしています。挿し直してアプリの「ホーム」を開き直すと、また使えるようになります。権限が失われた場合は、いったん登録を解除して追加し直してください。

4GB より大きいファイルをアップロードできない

FAT32 でフォーマットされた SD カード・USB ドライブは 1 ファイル 4GB までです。exFAT でフォーマットすると大きなファイルも保存できます。

使えないファイル名がある

SD カードや USB ドライブでも保存できるよう、\ : * ? " < > | を含む名前や、末尾が空白・ピリオドの名前は使えません。

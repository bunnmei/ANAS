拡張機能（特殊フォルダ）

ANAS ／ 仕様バージョン 1

フォルダに専用の画面を付けられます。ストレージ直下に .jisui/ のようなフォルダを作り、anas.json と HTML / CSS / JS を置くと、http://端末:8080/x/jisui/ でそのフォルダ専用の Web アプリが動きます。

完全な仕様書

細かい決まり・HTTP API・エラーコード・CSP などは spec/EXTENSION_SPEC.md にまとめています。アプリが動いていれば、端末の /_anas/spec.md（仕様書）と /_anas/sdk.d.ts（SDK の型定義）からも取得できます。

1. フォルダの形

/.jisui/              ← 「.」+ id。ストレージの直下に置く
  anas.json           ← マニフェスト（必須）
  app/                ← 画面（index.html が入口）。/x/jisui/ で配信
    index.html
    main.js
  data/               ← データ。SDK からはここだけ読み書きできる

2. anas.json

{
  "anas": 1,
  "id": "jisui",
  "name": "自炊本棚",
  "version": "1.0.0",
  "description": "スキャンした本を読む",
  "icon": "icon.svg"
}
キー内容
anas仕様のバージョン。1
id英小文字・数字・_・-。フォルダ名は . + id
name表示名
scope"self"（既定）: data/ の中だけ。"all": NAS 全体（アプリで許可したときだけ）
externalOriginsCDN など外部から読み込むときのオリジン（既定は外部通信なし）
networkANAS（端末）経由でアクセスする外部サイト。例: ["https://www.amazon.co.jp", "https://*.media-amazon.com"]（アプリで許可したときだけ）

3. SDK（データの読み書き）

<script type="module">
  import { anas, joinPath } from "/_anas/sdk.js";

  const entries = await anas.list("/");                 // data/ 直下の一覧
  img.src = anas.fileUrl("/covers/a.jpg");              // <img> / <iframe> / <video> 用の URL
  await anas.upload(joinPath("/books", file.name), file, {
    onProgress: (done, total) => console.log(done / total),
  });
  await anas.writeJson("/settings.json", { theme: "dark" }, { overwrite: true });
</script>

ほかに zipUrl（フォルダごと zip でダウンロード）・stat・exists・readText・readJson・listRecursive・mkdir・rename・remove があります。/_anas/base.css を読み込むと ANAS と同じ見た目（ライト / ダーク自動切替）になります。

anas.search("3日以内に追加したPDF") で、自分の data/ の中のファイルを文章で探せます（ファイル名・種類・日時・サイズから）。

外部サイトのデータを取ってくる

ブラウザの JS からは、CORS を許可していないサイトの中身は読めません。anas.json の network に書いて、アプリの「拡張」タブで許可すると、端末が代わりに取りに行きます。

const res = await anas.fetch("https://www.amazon.co.jp/dp/4000000000");
const doc = new DOMParser().parseFromString(await res.text(), "text/html");
const title = doc.querySelector("#productTitle")?.textContent?.trim();

// 画像などはブラウザを通さずに data/ へ保存
await anas.fetchToFile(imageUrl, "/.covers/4000000000.jpg", { overwrite: true });

使えるのは許可したサイトだけで、リダイレクト先も network に入っている必要があります。LAN 内の機器や端末自身にはアクセスしません。アプリの中（WebView）で開いたときも使えます。

4. 入れ方

  1. zip でインストールNAS の Web 画面の「拡張機能」→「zip からインストール」。data/ の中身は上書きされません。
  2. フォルダごとアップロードストレージの一番上で「フォルダごと」から .jisui フォルダを選ぶ →「再スキャン」。
  3. アプリでひな形を作るアプリの「拡張」タブ →「新しく作る」。

アプリの「拡張」タブで、拡張機能ごとに有効 / 無効を切り替えられます。

5. サンプル

自炊本棚（.jisui）

ScanSnap などでスキャンした PDF・画像フォルダを本棚に並べて読む。表紙の自動生成、見開き・右綴じ、読んだ位置の保存、PC からのドラッグ＆ドロップ追加。

KiCad ライブラリ（.kicad_symbol_footprint）

.kicad_sym・.kicad_mod・3D モデルを種類ごとに整理して、SVG でプレビュー。シンボル1つだけを切り出してダウンロードできます。

ノート（.notes）

Markdown（.md）のノートをプレビューで読み、ブラウザでそのまま編集。編集中は左右に並べてプレビュー、画像は貼り付けで保存、チェックボックスは押すだけで保存。

6. AI に作ってもらう

仕様書（EXTENSION_SPEC.md）と SDK の型定義（sdk.d.ts）を添えて、次のように頼みます。

ANAS の拡張機能を作ってください。仕様書と SDK の型定義を添付します。
- id: recipes
- 名前: レシピ帳
- やりたいこと: 写真付きのレシピを PC から登録・検索・閲覧したい
- 制約: フレームワークなし、外部 CDN なし、スマホでも見やすく、ダークモード対応
- 出力: .recipes/ フォルダの中身（anas.json と app/ 以下）をファイルごとに
